# **App Name**: NextUtils Dashboard

## Core Features:

- Interactive Voice Assistant: Provides voice-to-text transcription from the browser's native Web Speech API with a visual microphone pulse. The transcribed voice input will be processed as a tool to interpret commands or assist with navigation.
- Comprehensive Mortgage Calculator: Allows users to input principal, interest rate, and loan term, calculates mortgage details, and visualizes the breakdown using a Chart.js doughnut chart.
- Advanced Scientific Calculator: Offers a comprehensive suite of mathematical functions and operations powered by math.js for complex scientific calculations.
- Dynamic Component Navigation: Enables users to seamlessly switch between the Voice Assistant, Mortgage Calculator, and Scientific Calculator via an intuitive sidebar.
- Global Dark Theme Application: Implements a consistent, modern dark aesthetic across the entire dashboard for an optimized visual experience and reduced eye strain.
- Google AdSense Integration: Incorporates a designated placeholder div for Google AdSense banners at the bottom of all utility views within the dashboard.

## Style Guidelines:

- The visual scheme embraces a modern, dark aesthetic. The primary color, a calming indigo (#334D99), is derived from a deep violet-blue, signifying focus and technological sophistication. This color will be used for interactive elements and key accents. The background features a very dark, desaturated variant of the primary hue (#191D24), ensuring a cohesive and eye-friendly dark mode. A vibrant aqua accent color (#19CCE6) provides high contrast for calls to action and important indicators, drawing attention effectively.
- The application uses 'Inter', a grotesque-style sans-serif font, for both headlines and body text. Its modern, machined, and neutral look ensures excellent readability and maintains a clean, professional aesthetic suitable for a utility dashboard.
- Minimalist line icons with a consistent stroke weight should be used throughout the application. These simple vector-based icons will visually complement the dark theme and modern aesthetic, ensuring clarity and unobtrusive design for navigation and feature representations.
- The layout features a fixed sidebar for primary navigation, allowing quick access to different utility components. The main content area dynamically updates to display the selected tool. The design should be mobile-first and fully responsive, adapting gracefully to various screen sizes, potentially collapsing the sidebar into a compact menu on smaller devices. A designated footer area is reserved for the AdSense placeholder, consistent across all views.
- Subtle and functional animations should enhance user interaction without distraction. This includes smooth transitions when switching between components, subtle hover effects on interactive elements, and a distinct, visually engaging pulse animation for the voice assistant's microphone activity, clearly indicating its listening state.
